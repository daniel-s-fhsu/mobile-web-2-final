# Mobile Web 2 Final

Basic Expo marketplace app using Expo Router.

## Run

```bash
npm install
npx expo start
```

To start directly in the browser:

```bash
npx expo start --web
```

## Current Structure

- `app`: Expo Router entry files
- `routes`: route wrappers
- `page`: page components
- `components`: reusable UI
- `data`: local seed data
- `model`: plain JavaScript models
