# Mobile Web 2 Final

## Project Description

Mobile Web 2 Final is an Expo Router marketplace app for buying and selling student items. Users can create an account, log in, browse marketplace listings, search by item name, create listings, edit or delete their own listings, view listing details, and view short seller profile pages.

## Technologies Used

- Expo
- Expo Router
- React
- React Native
- React Native Web
- Firebase Authentication
- Cloud Firestore
- Firebase Storage SDK

## Install Dependencies

```bash
npm install
```

Create a local `.env` file using `.env.example` as the template:

```bash
EXPO_PUBLIC_FIREBASE_API_KEY=
EXPO_PUBLIC_FIREBASE_AUTH_DOMAIN=
EXPO_PUBLIC_FIREBASE_PROJECT_ID=
EXPO_PUBLIC_FIREBASE_STORAGE_BUCKET=
EXPO_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=
EXPO_PUBLIC_FIREBASE_APP_ID=
```

## Run the App

Start the Expo development server:

```bash
npx expo start
```

Start directly in the browser:

```bash
npx expo start --web
```

If environment variables or Firebase settings change, restart with a clean cache:

```bash
npx expo start --web --clear
```

## Firebase Services Used

- Authentication: email and password sign up, login, logout, and auth state tracking.
- Cloud Firestore: stores marketplace listings in the `listings` collection.
- Storage SDK: initialized in the Firebase service file, but listing images currently use image URLs instead of file uploads.

## Firestore Collection Structure

### `listings`

Each document represents one marketplace listing.

```js
{
  itemName: string,
  description: string,
  price: number,
  category: string,
  condition: string,
  location: string,
  imageUrl: string,
  sellerId: string,
  sellerEmail: string,
  createdAt: string,
  updatedAt: string // only present after editing
}
```

The document id is generated by Firestore and is used in listing detail routes.

## Known Issues

- Firestore must be created in Firebase Console before listing features can save or load data.
- Current Firestore test rules may expire and block all client reads/writes if not updated.
- Listing images are stored as external image URLs; Firebase Storage uploads are not implemented yet.
- Some local seed listings remain in the app for fallback/demo data, but new marketplace listings load from Firestore.
